# Itsy Bitsy Spider

Climb the waterspout. When the rain comes down, hold on, or it washes you out. Race up to five others to the sun, climb
twelve spouts solo for stars, or see how high you get in Monsoon before the flood catches you.

Play: https://onceworlds.com/play/itsy-bitsy-spider

Plain ES modules and Canvas 2D in `game/`, no build. The climbing, the rain, the bots and the races are pure modules covered
by `npm test` (Node 20+).

MIT licensed. Fonts: Alfa Slab One and Sofia Sans Condensed (SIL Open Font License, in `game/fonts`).
